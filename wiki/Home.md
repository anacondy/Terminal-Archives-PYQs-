## 🎯 Key Features

### 1. **Terminal Interface**
An authentic terminal-style UI with command prompts, color-coded output, and smooth animations.

### 2. **Smart Device Detection**
Automatically detects device type and optimizes the interface:
- 🐶 Android devices
- 🍎 iPhone devices
- 🍏 Other Apple devices
- 🪟 Windows computers
- 🐧 Linux systems
- 👽 Other devices

### 3. **Mobile Optimization**
Fully responsive design optimized for:
- 16:9 aspect ratio (standard mobile phones)
- 20:9 aspect ratio (ultra-wide phones)
- Landscape and portrait modes
- Touch interactions

### 4. **Search Functionality**
- **Desktop**: Press `Ctrl+K` (or `Cmd+K` on Mac)
- **Mobile**: Tap the search button at the bottom
- Real-time filtering through database
- Instant results display

### 5. **Statistics Tracking**
Hidden stats page accessed by pressing F+S for 2+ seconds:
- Daily visit counts
- Monthly statistics
- Device breakdown with emojis
- Historical data

## 💡 How to Use

### Searching for Papers

**On Desktop:**
1. Press `Ctrl+K` (or `Cmd+K` on Mac)
2. Type your search query (e.g., "Physics 2024")
3. Press Enter
4. Click on results to access papers

**On Mobile:**
1. Tap the search button at the bottom of the screen
2. Enter your search query
3. Tap Enter or the search button
4. View and access results

### Viewing Statistics

1. Press and hold the `F` key
2. While holding F, press and hold the `S` key
3. Keep both keys held for at least 2 seconds
4. The stats modal will appear
5. Press Escape or F+S again to close

### Keyboard Shortcuts

| Shortcut | Action |
|----------|--------|
| `Ctrl+K` / `Cmd+K` | Open search modal |
| `Enter` | Execute search |
| `Escape` | Close any modal |
| `F+S` (hold 2s) | Show statistics |

## 🔧 Technical Overview

- **Frontend-Only**: No backend required
- **Storage**: LocalStorage for stats tracking
- **Frameworks**: Pure HTML, CSS, JavaScript (no frameworks)
- **Performance**: Optimized animations with GPU acceleration
- **Security**: XSS protection, input sanitization
